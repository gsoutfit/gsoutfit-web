# 🎩 Gentleman Savage — Luxury Menswear & Streetwear E-Commerce

> *Sophisticated Tailoring Meets Raw Contemporary Streetwear.*

A production-grade, full-stack luxury e-commerce platform built with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**.

---

## ✨ Key Features & Capabilities

- 🇧🇩 **Native Bangladeshi Commerce**: All pricing in **Bangladeshi Taka (`৳` / BDT)** with doorstep **Cash on Delivery (COD)**, **bKash**, and **Nagad** (*247# / *167# Send Money & TrxID verification).
- 🌐 **Bilingual Architecture (English / বাংলা)**: Comprehensive customer-facing translation dictionary with instant language toggling and zero-flicker persistence.
- ⚡ **Advanced Active Filters Dashboard**: Multi-criteria animated filter chips, live garment match counters, shareable query URLs, and 1-click wardrobe presets (`⚡ Flash Deals`, `🔥 Bestsellers`, `❄️ Winter Drop`, `☀️ Summer Drop`, `💎 In Stock Only`).
- 🛍️ **Haute Couture Shopping Bag**: Interactive slide-out drawer, dynamic free delivery progress bar (`৳1,500+` threshold), promo code engine, and line-item sizing controls.
- 🔒 **Enterprise-Grade Security**: PBKDF2 cryptographic password hashing, Edge HMAC-SHA256 session signatures, HTTP-only secure cookies, and strict CSP/HSTS headers.
- 🛠️ **Full Executive Admin Suite**: Real-time inventory tracking, order status dispatches, customer registry, theme color customizer, and sales analytics.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open in browser
http://localhost:3000
```

---

## ☁️ Deployment on Vercel (1-Click)

1. Push this repository to your **GitHub** account (`gsoutfit/gsoutfit-web`).
2. Log into **[Vercel](https://vercel.com)** and click **"Add New..."** → **"Project"**.
3. Import the `gsoutfit-web` repository.
4. Set the Environment Variables:
   - `SESSION_SECRET`: `gs_production_secret_key_gentleman_savage_2026_unbreakable_salt`
   - `NODE_ENV`: `production`
5. Click **Deploy**!
